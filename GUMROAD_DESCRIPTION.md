**Full Description:**

---

CrisisGrid is a ready-to-deploy web application that helps neighborhoods coordinate during emergencies — storms, power outages, floods, wildfires, or missing persons — when 911 is overwhelmed.

Block captains can declare a crisis, view a priority-sorted task queue of households that need help, and communicate with residents across their zone. Households self-register their needs and available resources. Everything runs on a single server with zero paid API dependencies.

**What you get:**
- Complete source code (React frontend + FastAPI backend)
- SQLite database (auto-initializes, no setup)
- One-command production deploy script (`bash start.sh`)
- Clean setup instructions in README

**Key Features:**

- Household registration with vulnerability scoring (mobility, medical equipment, language needs, vehicle access)
- Crisis declaration system — storm, power outage, flood, wildfire, missing person
- Auto-generated, priority-sorted task queue for affected households
- Tasks can be claimed, completed, or flagged with notes
- Direct messaging between households + zone-wide captain broadcasts
- Interactive map (OpenStreetMap — free, no API key needed)
- Debrief reports with coverage metrics and CSV export
- Admin dashboard with audit logging
- Captain application + approval workflow
- Drill/demo mode so communities can practice without causing panic
- Optional email alerts via SMTP (works with Gmail, SendGrid, etc.)

**Tech Stack:**
- Frontend: React 18, Vite, Leaflet (maps)
- Backend: Python, FastAPI, SQLite
- No paid APIs. No vendor lock-in.

**Requirements:**
- Node.js 18+
- Python 3.9+
- Any VPS or host that runs Python (Railway, Render, Fly.io, DigitalOcean, etc.)

**Who is this for:**
- Civic hackers and community organizers who want to deploy a real tool for their neighborhood
- Developers looking for a solid FastAPI + React starter to build on
- Emergency management orgs that need a lightweight, self-hostable coordination tool
- Anyone who wants to own their infrastructure without paying for SaaS
